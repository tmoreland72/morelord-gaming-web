# Foundry activation workflow update

- Activation links now include the temporary code and jump directly to the Foundry connection section.
- Signed-out users return to the same activation request after authentication.
- The activation form is prefilled and clearly indicates that Foundry is waiting.
- Successful approval replaces the form with a prominent return-to-Foundry message and a close-tab button.
- Public Morelord Core documentation reflects the updated workflow.
